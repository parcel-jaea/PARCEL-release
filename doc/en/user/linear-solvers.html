8 Linear Solvers

This chapter describes the iterative algorithms used in the library routines. Throughout, we consider solving the linear system Ax=bAx = b whose coefficient matrix AA is a real nglobal×nglobaln_{global} \times n_{global} matrix. Each section gives the algorithm and its notation. The details of the convergence check, the handling of breakdowns and non-finite values, and the returned values are given in the solver() section of each solver in the API Reference (“Common Handling in the Linear Solvers”). ⟨⋅,⋅⟩\langle \cdot,\cdot \rangle denotes the inner product and ∥⋅∥\|\cdot\| the 2-norm. All four linear solvers (pcg, pbicgstab, pgmres, pcagmres) check convergence by comparing the relative residual ∥r∥/∥b∥\|r\| / \|b\| with the value toltol set by set_tolerance() (convergence when ∥r∥/∥b∥<tol\|r\| / \|b\| < tol). The matrices each method can handle and its characteristics are listed below.

Method Class Target matrix Characteristics
Preconditioned conjugate gradient method parcel::krylov::pcg Symmetric positive definite (the preconditioner matrix also symmetric positive definite) Few operations and collective communications per iteration
Preconditioned biconjugate gradient stabilized method parcel::krylov::pbicgstab Symmetric or nonsymmetric Right preconditioning. Performs SpMV and preconditioning twice each per iteration. The residual does not necessarily decrease monotonically
Preconditioned generalized minimal residual method parcel::krylov::pgmres Symmetric or nonsymmetric Right preconditioning. Minimizes the residual norm within the restart length mm
Preconditioned communication-avoiding generalized minimal residual method parcel::krylov::pcagmres Symmetric or nonsymmetric (the moment method only for symmetric matrices without preconditioning) Right preconditioning. Generates ss basis vectors at once and orthogonalizes them, performing iterations equivalent to GMRES(stst) with fewer collective communications. Whether the orthonormal basis QQ is formed explicitly can be selected with set_explicit_q() (if not, orthogonalization uses the Cholesky factorization of the Gram matrix)

In the algorithms and formulas of this manual, iteration numbers are written as parenthesized superscripts (x(i)x^{(i)}, α(i)\alpha^{(i)}), and components of a vector and indices within a set of vectors as subscripts (xix_{i}, vjv_{j}). A superscript without parentheses is a power ((AK−1)s(AK^{-1})^{s}), ATA^{T} is the transpose and A−1A^{-1} the inverse. Matrices are written in upper case, vectors and scalars in lower-case italics, and English keywords and function names (solve\mathrm{solve}, chol\mathrm{chol}, etc.) in upright type. nglobaln_{global} is the order of the matrix (the number of global rows) and nlocaln_{local} the number of rows owned by each rank. Symbols are defined per section and may have a different meaning in another section.

The convergence status constants and their meaning for each solver are summarized in “Convergence Status” in the API Reference.

The biconjugate gradient stabilized method (Bi-CGSTAB) is a Krylov subspace method for nonsymmetric matrices. The preconditioner is applied as a right preconditioner; that is, the iteration is performed on AK−1AK^{-1} and the solution is updated with the directions p̂\hat{p} and ê\hat{e} multiplied by K−1K^{-1}, so the residual r(i)r^{(i)} corresponds to the unpreconditioned residual b−Ax(i)b - Ax^{(i)}.

8.3 Preconditioned Generalized Minimal Residual Method [1]

The generalized minimal residual method (GMRES(m)) is a Krylov subspace method for nonsymmetric matrices. It updates the approximate solution by minimizing the residual norm over the subspace built by mm steps of the Arnoldi process, and then restarts the iteration using the result as the initial guess (restarting). The PARCEL pgmres uses right preconditioning: the Arnoldi process is performed on AK−1AK^{-1}, and K−1K^{-1} is applied only when the approximate solution is updated. The residual being minimized is therefore the unpreconditioned residual b−Axb - Ax itself. The classical Gram-Schmidt method and the modified Gram-Schmidt method are available as the orthogonalization methods of the Arnoldi process.

8.4 Preconditioned Communication-Avoiding Generalized Minimal Residual Method [2,3]

The communication-avoiding generalized minimal residual method (CA-GMRES(s,t)) is a Krylov subspace method for nonsymmetric matrices. It generates, at once, the basis vectors corresponding to ss iterations of GMRES(m) and orthogonalizes them block by block. This is repeated tt times, the approximate solution is updated with the resulting stst basis vectors, and the iteration is restarted with the result as the initial guess. m=stm = st corresponds to the restart length of GMRES(m). Mathematically, CA-GMRES(s,t) and GMRES(m) have equivalent convergence, and by applying a communication-avoiding QR factorization, CA-GMRES reduces the number of collective communications compared with GMRES(m). However, because ss basis vectors are generated at once, if ss is too large, rounding errors destroy the orthogonality of the basis vectors and the convergence becomes worse than that of GMRES. PARCEL supports only the monomial basis (vi+1=AK−1viv_{i+1} = AK^{-1}v_{i}); the Newton basis is not implemented. As in pgmres, right preconditioning is used.

  • Algorithm

x(0)x^{(0)} is the initial guess passed as the argument x of solver(), x(j)x^{(j)} is the approximate solution at the start of the jj-th restart, KK is the preconditioner matrix specified by set_precon_algo() and related functions, ss and tt are the values set by set_restart(s, t) (default s=8s = 8, t=4t = 4), and toltol is the value of set_tolerance() (default 1.0e-8). The maximum number of restarts JJ is determined from the value NN of set_max_iteration() (default 10000) as J=⌈N/(st)⌉J = \lceil N/(st) \rceil (if NN is not a multiple of stst, the last restart solves the least-squares problem with the remaining columns only). The algorithm below forms the orthonormal basis QQ explicitly. The case without forming QQ is described below.

8.4.1 How Q Is Formed (set_explicit_q)

pcagmres lets you choose with set_explicit_q(mode) whether the orthogonalized basis QQ is formed explicitly (the value can be obtained with get_explicit_q()). mode is one of the following constants in the namespace parcel::krylov.

Constant Value Behavior
CAGMRES_Q_AUTO (default) 0 Forms QQ as in the algorithm above, except that QQ is not formed when QR_CHOLESKYQR is used with t=1t = 1
CAGMRES_Q_EXPLICIT 1 Always forms QQ (also with QR_CHOLESKYQR and t=1t = 1)
CAGMRES_Q_IMPLICIT 2 Does not form QQ for any tt (below). The QR factorization is QR_CHOLESKYQR (used if set_qr_algo() is not called) or QR_CAGMRES_CHOLESKYQR (the moment method)

The combinations of CAGMRES_Q_IMPLICIT with QR_CGS or QR_MGS, and of QR_CAGMRES_CHOLESKYQR with CAGMRES_Q_AUTO or CAGMRES_Q_EXPLICIT, throw std::invalid_argument at the entry of solver() (the setters may be called in any order, so the combination is checked at the entry). The selected mode is shown at the end of the timing line (the pcagmres time line), such as Q = auto: formed or Q = implicit: not formed, CholeskyQR.

8.5 Precision of Orthogonalization and of the Basis

GMRES-type solvers iterate while orthogonalizing the basis of the Krylov subspace. In pgmres and pcagmres, the precision in which the basis is stored and the precision in which orthogonalization is computed can be specified separately (for the syntax see “Calling a Linear Solver” in “Usage”).

In this section, nlocaln_{local} is the local number of rows and mm is the restart length of pgmres (set_restart(m)). ss and tt are the parameters of CA-GMRES(s,t) (pcagmres), specified with set_restart(s, t) (default s=8s = 8, t=4t = 4).

  • ss: the number of basis vectors generated in a row without orthogonalization in one block. From the first vector vv of the block, the s+1s+1 vectors of the monomial basis v,AK−1v,…,(AK−1)svv, AK^{-1}v, \ldots, (AK^{-1})^{s}v are generated, and these s+1s+1 vectors are QR-factorized together. There is no collective communication while the ss SpMVs and preconditionings are performed in a row.
  • tt: the number of blocks generated in one restart. From the second block on, each block is orthogonalized against the orthogonalized basis QQ of the previous blocks before its QR factorization. Since the last vector of a block is the first vector of the next block, one restart has st+1st+1 basis vectors, and the restart length corresponds to GMRES(stst) (Linear Solvers chapter).

With rounding errors, the orthogonalized basis QQ is not exactly orthogonal. The loss of orthogonality ∥I−QTQ∥\|I - Q^{T}Q\| is determined by the unit roundoff uu of the precision used to compute the orthogonalization and by the condition number κ(V)\kappa(V) of the basis VV before orthogonalization. It is proportional to uκ(V)u\,\kappa(V) for the modified Gram-Schmidt method [8], and to uκ(V)2u\,\kappa(V)^{2} for the classical Gram-Schmidt method [9] and the Cholesky QR method [11]. uu is about 1.1×10−161.1 \times 10^{-16} in double precision, about 6.0×10−86.0 \times 10^{-8} in single precision, and about 4.9×10−44.9 \times 10^{-4} in half precision. The Cholesky QR method fails when uκ(V)2u\,\kappa(V)^{2} approaches 1, because the Gram matrix is then no longer numerically positive definite. In addition, storing the orthogonalized QQ at a lower precision degrades the orthogonality by its rounding (relative uu in each entry of QQ).

The Arnoldi process of pgmres orthogonalizes each new vector against the previously orthogonalized basis, one vector at a time. GMRES with the modified Gram-Schmidt method is backward stable, and orthogonality is lost significantly only after the residual has become sufficiently small [10]. Therefore, even with a low precision for the orthogonalization precision TGS, the iteration proceeds, and the effect appears mainly as a lower limit on the achievable residual (the limit grows with uu).

In pcagmres, orthogonalization has two stages, and ss and tt act on them respectively.

  • Within a block (ss acts): the s+1s+1 vectors of the monomial basis are generated without orthogonalization, so their condition number grows rapidly with ss. Since they are QR-factorized, the computation precision of the QR factorization directly determines whether orthogonalization succeeds. In particular, the Cholesky QR method (QR_CHOLESKYQR of pcagmres, including the variant that does not form QQ, CAGMRES_Q_IMPLICIT) depends on κ(V)2\kappa(V)^{2}, so with a large ss the factorization itself easily breaks down at low precision. This ill-conditioning is also why the Cholesky QR variants of pcagmres cannot be used with FP16 data or computation precision (the variants that form QQ can be used; “Known Limits at Low Precision”).
  • Between blocks (tt acts): the kk-th block (k=1,…,t−1k = 1, \ldots, t-1) subtracts its projection onto the previous QQ (sk+1sk+1 vectors) once (the block classical Gram-Schmidt method, without reorthogonalization) before the QR factorization within the block. The loss of orthogonality between blocks depends on the computation precision of the single projection and on the condition number of the block before projection, and as blocks are stacked (larger tt), errors in orthogonality to the previous blocks may accumulate in the basis.

The detection of rank deficiency of the basis (a lucky breakdown) uses a threshold determined from u=max⁡(uTbasis,uTcalcQR)u = \max(u_{Tbasis}, u_{TcalcQR}) (100u100\sqrt{u} for the Cholesky QR method, 1000u1000u otherwise).

The samples fix TcalcQR and THessenberg to double precision for the following reason. Lowering the precision reduces memory and data movement for the basis (Tbasis), which holds st+1st+1 or more vectors of length nlocaln_{local}. On the other hand, what decides whether orthogonalization succeeds is the computation precision of the orthogonalization within and between blocks (TcalcQR and THessenberg in pcagmres, and TcalcQR in the variant that does not form QQ, CAGMRES_Q_IMPLICIT). These are the precisions in which dot products are accumulated while reading the basis, and raising them does not change the amount of basis data read and written. The stored matrices (RR, the Hessenberg matrix, etc.) are small, about (st+1)(s+1)(st+1)(s+1). Hence the basis alone is lowered to match the data precision, while the orthogonalization computations and the small matrices are kept in double precision. The orthogonality is then preserved to the level determined by the rounding of Tbasis, which stores the basis QQ. The C and Fortran wrapper (capi/wrapper_parcel_sycl.cpp) gives these two with the macro parcel_solver_calc_qr_type (default parcel_double), and the verification sample tests/verify/parcel_krylov_sample_verify.cpp fixes them to parcel_double. TGS and THessenberg of pgmres are both given the data precision (the library default is parcel_double). All 13 representative configurations in “Precision Configurations” use double precision for TcalcQR and THessenberg of pcagmres (including the variant that does not form QQ). Convergence when these are lowered has not been checked.

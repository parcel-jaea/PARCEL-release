1 共通事項

　本書は PARCEL の API を言語ごとの章に分けて示す. 言語によらない事項 (ソルバ, 入力の行列, 設定の意味と既定値, 定数, 結果の意味, 収束状態, MPI での扱い) は本章と次章「ソルバごとの収束判定」にまとめ, 各言語の章にはその言語での名前と書き方, エラーの知らせ方, 例を示す. 利用者は本章・次章と, 使う言語の章を読めばよい. 言語はページの上のタブで切り替える.

　各言語の章の冒頭に, 本章の設定・定数・結果とその言語での名前の対応表を置く.

1.2 ソルバ

　PARCEL は次の 7 つのソルバを持つ. ソルバの名前は全言語で共通である. アルゴリズムは利用者ガイドの線形ソルバの章と固有値ソルバの章に, 選び方はソルバの選び方に示す.

ソルバ 方法 解く問題
pcg 前処理付き共役勾配法 Ax=bAx = b. AAと前処理行列KKが対称正定値
pbicgstab 前処理付き安定化双共役勾配法 Ax=bAx = b (非対称行列)
pgmres 前処理付き一般化最小残差法 (右前処理, リスタート付き) Ax=bAx = b (非対称行列)
pcagmres 前処理付き通信削減型一般化最小残差法 (CA-GMRES). ss本の基底をまとめて作り, QR 分解で直交化する Ax=bAx = b (非対称行列)
power べき乗法 AAの絶対値最大の固有対 1 組
inverse_power 逆べき乗法. 各反復で内部の線形ソルバがAy=xAy = xを解く AAの絶対値最小の固有対 1 組
ks_arnoldi Arnoldi 過程と Krylov-Schur リスタート. 非対称行列, 複素共役対の固有値にも対応する AAの絶対値の大きい側の複数の固有対. shift-invert ではシフトσ\sigmaに近い固有対

　固有値ソルバは標準固有値問題Ax=λxAx = \lambda xを扱う. 前処理後の行列のスペクトルを選ぶと, AAの代わりにAK−1AK^{-1}の固有値を求める. ソルバはビルドから外せる (利用者ガイドの「ビルドするソルバの取捨」). 外したソルバを呼んだ場合の扱いは各言語の章に示す.

1.4 入力の行列

　係数行列は CRS 形式で与える. MPI で並列に解く場合は, 各ランクが連続した行のブロック (大域行番号nstartnstartからnlocaln_{local}行) を受け持ち, その行の部分だけを渡す. 形式の説明は利用者ガイドのデータ構造の節に示す.

  • 行ポインタは長さnlocal+1n_{local} + 1で, 担当行の先頭からの位置を表す. 単調非減少で, 最後と最初の差が担当行の非零要素数に等しい.
  • 列番号は行列全体での大域の番号である.
  • 番号付けは 0 始まりである. C言語・Fortran の API では 1 始まりも選べる.
  • 行数・非零要素数・行ポインタ・列番号の整数は 64 ビットで渡す (C++ では整数型をビルドで 32 ビットにもできる).

　次の条件はライブラリが検査し, 満たさなければ全ランクが同じエラーになる (エラーの知らせ方は各言語の章).

  • 各ランクの担当行数は 1 以上である (行を持たないランクは扱えない). ランクごとに異なってよい.
  • 全ランクの行ブロックを合わせたものが[0,nglobal)[0, n_{global})を重複・欠落なく覆う. ランク番号の順に並んでいる必要はない.
  • 行ポインタが上の条件を満たし, 列番号が[0,nglobal)[0, n_{global}) (1 始まりでは[1,nglobal][1, n_{global}]) に収まる.
  • 1 つのランクの非零要素数と, 担当行数と袖の要素数の和が, ライブラリ内部の局所の添字の範囲 (既定の 32 ビットでは231−12^{31} - 1以下) に収まる. 超える場合はランク数を増やす (C++ ではビルドで局所の添字を 64 ビットにもできる).

　次の条件は検査しないので, 満たさないと誤った結果を黙って返しうる.

  • 対称な行列でも, 上三角と下三角の両方の要素を格納する (片側だけを格納する形式は無い).
  • 各行に対角要素を格納する (値が 0 でも格納する). Jacobi 系の前処理が対角要素を使う.
  • 各行の列番号は昇順に並べ, 同じ列番号を 1 行に 2 回以上入れない.

　MPI なしのビルドでは 1 プロセスが行列の全体を持つ (担当行は全行).

1.5.1 前処理の補足

  • GPU ではブロック Jacobi 前処理は遅く, Jacobi 前処理を推奨する. 前処理の種類は利用者ガイドの前処理の章に示す.
  • Jacobi 前処理は係数行列AAの行ポインタ・列番号を複製せずに共有し, 既定ではB=DA−1RB = D_A^{-1}Rの値も持たずに適用のたびにAAの値から計算する (A64FX 向けのビルドの既定は値を保持する). 前処理は求解の中で作られ求解の中だけで使われるので, 求解の実行中にAAを破棄・変更しない. ビルド時に-DPARCEL_JACOBI_ONTHEFLY=0を与えるとBBの値を保持し, メモリを使って GPU で前処理が速くなる (利用者ガイドの「メモリと速さの選択」). 行列スケーリングが有効な場合と, 係数行列・前処理行列・前処理の演算精度のいずれかが double-double の構成では, 既定でも値を保持する.
  • ブロック数とスケーリングを自動にした場合の実際の値は, 環境変数PARCEL_PRECON_VERBOSEを設定すると表示される.
  • スケーリングはポイント Jacobi 前処理と前処理なしでは使われない.

1.5.2 固有値ソルバの補足

  • 前処理後の行列のスペクトルを求めない場合 (既定), 前処理の設定は外側の固有値反復に使われない. 前処理の設定だけを与えてもAAの固有値は速く求まらない. inverse_power と shift-invert で内部線形ソルバを速くしたい場合は, 内部線形ソルバの前処理を設定する.
  • 前処理後の行列のスペクトルを求める場合, 内部線形ソルバ (inverse_power, ks_arnoldi の shift-invert) は右前処理の pgmres が(AK−1−σI)z=v(AK^{-1} - \sigma I)z = vを解いてzzを返す形になり, 前処理はKKそのものである (内部線形ソルバの前処理の設定は使わない).
  • 内部線形ソルバの設定は, inverse_power と ks_arnoldi の shift-invert で使われ, power とシフトなしの ks_arnoldi では使われない. 内部 pgmres の直交化は修正 Gram-Schmidt 法に固定である.
  • 内部線形ソルバが収束しなくても外側の反復は続く. 収束しなかった回数は結果で得る. 外側の収束状態には反映しない.
  • ks_arnoldi の shift-invert で前処理後の行列のスペクトルを求めない場合, 内部 pgmres は(A−σI)z=v(A - \sigma I)z = vを解き, KinK_{in}をA−σIA - \sigma Iから作る. A−σIA - \sigma Iの与え方は各言語の章に示す.
  • 内部線形ソルバの誤差はそのまま固有値の推定の誤差になるため, 外側のtoltolより内部線形ソルバを厳しく収束させる必要がある.

1.5.3 pcagmres のQQの作り方と QR 分解

　QQの作り方 (定数) は次のとおりである.

作り方 動作
AUTO QR 分解が Cholesky QR かつt=1t = 1のときだけQQを作らず, それ以外はQQを作る
EXPLICIT 常にQQを作る (Cholesky QR でt=1t = 1でも作る)
IMPLICIT どのttでもQQを作らない. 基底VVの Gram 行列の Cholesky 分解からRRだけを求め, 解の更新にV(R−1y)V(R^{-1}y)を用いる. QR 分解は Cholesky QR またはモーメント法による Cholesky QR に限る

　QQの作り方と QR 分解の組合せは, 設定を与える順序によらないよう求解の入口で検査し, 次の場合は受け付けない (全ランクで同じ判定).

  • IMPLICIT で, 古典・修正 Gram-Schmidt を明示した (QR 分解を指定していなければ Cholesky QR を使う).
  • モーメント法による Cholesky QR を AUTO または EXPLICIT と組み合わせた.
  • モーメント法による Cholesky QR で, 前処理がなしでない, またはssが 2 以上の偶数でない.

　モーメント法による Cholesky QR (モーメント法) はAAが対称の場合に限る. これは検査せず, 非対称なAAでは誤ったRRを用いて誤った結果を返す. AUTO と EXPLICIT は, t=1t = 1の Cholesky QR 以外では同じ計算を行う. IMPLICIT は計算の順序が異なるので, 同じss, ttと QR 分解でも結果は丸め誤差の範囲で異なる. IMPLICIT では Cholesky QR 法の直交性の誤差が基底の条件数の 2 乗に比例するので, ssを大きくすると収束が悪化しうる. FP16 のデータ精度・計算精度では, Cholesky QR 系 (IMPLICIT とモーメント法) を使わない (ss, ttによらず NaN または未収束になる. 検査はしない). 方法は利用者ガイドの線形ソルバの章と QR分解の章に示す.

1.7 結果

　求解は解 (固有値ソルバでは固有値と固有ベクトル) のほか, 次の値を返す. 値は全ランクで同じである. 意味の詳細はソルバごとに異なり, 収束状態の節と次章に示す.

結果 意味
収束状態 収束状態の定数のいずれか. 正は収束, 負は失敗, 0 は求解を実行していない
反復回数 数え方はソルバごとに異なる (下表)
残差 収束判定値と比べた相対値 (下表). 計算していなければ NaN
真の残差 線形ソルバの終了時に計算した∥b−Ax∥/∥b∥\|b - Ax\|/\|b\|. 追加の計算をせずに返す. 固有値ソルバでは NaN. pcg・pbicgstab の残差は漸化式の残差なので, 丸め誤差により真の残差と離れることがある. 解の精度を確かめる場合はこちらを見る
収束した固有対の数 ks_arnoldi の最後の収束判定で, nevnev個のうち判定値を満たした固有対の数 (NaN は数えない. 不変部分空間などで真の残差を確かめた場合はその数). 収束時はnevnev. 他のソルバでは 0

1.7.1 固有値と固有ベクトルの出力

  • power と inverse_power は固有値 1 個と固有ベクトル 1 本を返す. 固有値は実数である.
  • ks_arnoldi は固有対を|θ||\theta|の降順 (shift-invert ではσ\sigmaに近い順) にkkeepk_{keep}組返す. 収束を保証するのは先頭のnevnev組である.
  • 固有値は実部と虚部の組で表す. 固有値が複素共役対の場合, 対応する固有ベクトルは実部と虚部の 2 本として連続して格納する.
  • 有効次元がkkeepk_{keep}に満たないまま終えた場合, 足りない固有対は 0 で返す (rank 0 がその旨を表示する). shift-invert の逆変換で|θ|2≤10−300|\theta|^{2} \leq 10^{-300}となる固有値は+∞+\inftyを返す.
  • 各言語での配列の並びは各言語の章に示す.

1.8.2 線形ソルバに共通の扱い

　線形ソルバ (pcg, pbicgstab, pgmres, pcagmres) では, ∥b∥=0\|b\| = 0の場合は反復せずにx=0x = 0を返し, 収束状態は CONVERGED_RTOL (反復回数 0, 残差・真の残差は 0) とする. rank 0 は||b|| = 0 : x = 0の行を書く.

　初期値x(0)x^{(0)}による初期残差の相対残差∥b−Ax(0)∥/∥b∥\|b - Ax^{(0)}\| / \|b\|がtoltol未満の場合 (x(0)x^{(0)}がすでに解である場合を含む) は, どの線形ソルバも反復せずに CONVERGED_RTOL (反復回数 0) を返し, xxは初期値のまま変えない. 残差と真の残差はこの初期残差の相対残差である.

1.8.3 標準出力

　rank 0 は求解の最後に次の形式の 1 行を標準出力に書く (非有限値はn/a). inverse_power は, linsolve_failures = ...を, ks_arnoldi は, ks_nconv = 収束数/nev (shift-invert ではlinsolve_failuresも) を加える.

　例: converged_reason = 1 (CONVERGED_RTOL) , its = 27 , residual = 4.200000e-10 , true_residual = 4.211375e-10

　このほか rank 0 は, 反復の途中経過と計算時間の内訳を書く. 線形ソルバは終了時の真の相対残差をfinish : residual true normの行に書く. pcagmres は反復の前の判定で戻る場合はこの行を書かない. 標準出力の書式は API に含めない. プログラムから結果を得る場合は各言語の結果の取得方法を用いる.

1.9 設定の扱いと MPI

  • 設定は求解のときに使われる. 設定は全ランクで同じ値を与える. 取りうる値を外れた値は受け付けず, 全ランクが同じ判定でエラーになる.
  • 求解は集団操作である (MPI_Barrier, 内積のMPI_Allreduce, SpMV の袖通信). 行列を渡したコミュニケータの全ランクが, 同じソルバと同じ設定で呼ぶ.
  • 求解の入口では, 入力の行列の条件, ks_arnoldi の部分空間の大きさ (m≤nglobalm \leq n_{global}を含む), pcagmres の QQの作り方と QR 分解の組合せ を検査する. いずれも集団通信の前に, 全ランクが同じ判定でエラーになる.
  • 求解は収束しなくてもエラーにならない. 結果を使う前に収束状態を確かめる. 収束状態は求解の入口でリセットされ, 出口で設定される.
  • デバイスメモリの確保に失敗した場合と, 行列の大きさがライブラリ内部の整数の範囲を超える場合はエラーになる. これらは一部のランクだけで起きうるので, 扱いは言語ごとに異なる (各言語の章).
  • 密行列の LAPACK 計算 (ks_arnoldi) は rank 0 が行い, 結果を全ランクに配る. 判定に用いる値はいずれも全ランクで集約した値なので, 全ランクが同じ分岐を取る.

1.10 精度

　PARCEL は, データを保持する精度 (データ精度) と演算の精度 (計算精度) を, 演算 (SpMV, 前処理, ベクトル演算, 内積) とデータ (行列, ベクトル, 前処理行列など) ごとに選べる. 型は半精度 (FP16), 単精度, 倍精度, long double, double-double (4倍精度相当) である. 精度の選び方は言語によって異なる.

言語 精度の指定
C++ 演算ごと・データごとにテンプレート引数で選ぶ (PARCELデータ型)
C言語・Fortran ラッパのコンパイル時のマクロで決まり, 実行時には変えられない (既定はすべて倍精度). 入出力の配列は倍精度
Python 倍精度だけ

　半精度を使う構成では, 精度で届く相対残差に下限があり, それより小さい収束判定値では停滞するか NaN で破綻する. 制約の詳細は利用者ガイドの使用方法の章の「精度の指定」と「数値精度と再現性」に示す.

2 ソルバごとの収束判定

　ソルバごとに, 収束判定の方法と, 破綻・非有限値に出会ったときの収束状態と返す値を示す. 言語によらない. 表の「解」「反復回数」「残差」は結果の値であり, NNは最大反復回数である. 方法の全体は利用者ガイドの線形ソルバの章と固有値ソルバの章に示す.

2.1 pcg

　反復ii (i=0,1,…i = 0, 1, \ldots) ごとに, 探索方向p(i)p^{(i)}とステップ幅α(i)\alpha^{(i)}で解をx(i+1)=x(i)+α(i)p(i)x^{(i+1)} = x^{(i)} + \alpha^{(i)}p^{(i)}, 残差を漸化式r(i+1)=r(i)−α(i)Ap(i)r^{(i+1)} = r^{(i)} - \alpha^{(i)}Ap^{(i)}で更新した直後に, 漸化式の相対残差∥r(i+1)∥/∥b∥\|r^{(i+1)}\| / \|b\|を調べる (方法の全体は利用者ガイドのアルゴリズム). 判定に用いるのは漸化式の残差であり, 真の残差b−Ax(i+1)b - Ax^{(i+1)}ではない. 反復の前に初期残差r(0)=b−Ax(0)r^{(0)} = b - Ax^{(0)}の相対残差を調べ, toltol未満なら反復しない. 結果は次のとおりである (上の行から順に調べる).

条件 収束状態 解 反復回数 残差
反復の前に初期残差の相対残差 <tol< tol CONVERGED_RTOL 初期値 (変えない) 0 初期残差の相対残差 (真の残差も同じ値)
相対残差が非有限 (NaN / Inf) DIVERGED_NANORINF その反復のx(i+1)x^{(i+1)} i+1i + 1 その非有限値
相対残差 <tol< tol CONVERGED_RTOL x(i+1)x^{(i+1)} i+1i + 1 その相対残差
NN回の反復で上に当たらない DIVERGED_ITS x(N)x^{(N)} NN 最後の相対残差

　∥b∥=0\|b\| = 0の場合は線形ソルバに共通の扱いによる. ゼロ割りなどの破綻は検出しないので DIVERGED_BREAKDOWN にはならず, その結果残差が非有限になれば DIVERGED_NANORINF となる. rank 0 は反復ごとに反復回数 : residual norm = ...の行を書く. 真の相対残差∥b−Ax∥/∥b∥\|b - Ax\| / \|b\|は終了後に計算してfinish : residual true normの行に書き, 真の残差として返すだけで, 判定には用いない.

　解の更新は環境変数PARCEL_PSTEP (既定 1) 反復ぶんをまとめて行い, 終了時 (どの条件で終えた場合も) に残りを加えるので, 返すxxは上の表のとおりである. 既定の 1 では探索方向を 1 本だけ持つ. PARCEL_PSTEP=4では探索方向の履歴 4 本を持ち (ベクトル 3 本分のメモリを使う), 解の読み書きが減って少し速くなる (利用者ガイドの「メモリと速さの選択」). PARCEL_PSTEPを 2 以上にすると, 反復途中のxxは最大PARCEL_PSTEP反復ぶん遅れる (利用者ガイドの「漸化式の残差と真の残差」).

2.2 pbicgstab

　反復ii (i=0,1,…i = 0, 1, \ldots) では, 探索方向p(i)p^{(i)}からp̂=K−1p(i)\hat{p} = K^{-1}p^{(i)}, q=Ap̂q = A\hat{p}, α=ρ(i)/⟨r*,q⟩\alpha = \rho^{(i)} / \langle r^{\ast},q \rangle (r*r^{\ast}は初期残差r(0)r^{(0)}に固定した双対残差, ρ(i)=⟨r*,r(i)⟩\rho^{(i)} = \langle r^{\ast},r^{(i)} \rangle), 中間の残差e=r(i)−αqe = r^{(i)} - \alpha q, ê=K−1e\hat{e} = K^{-1}e, v=Aêv = A\hat{e}, ω=⟨e,v⟩/⟨v,v⟩\omega = \langle e,v \rangle / \langle v,v \rangleを求め, 解をx(i+1)=x(i)+αp̂+ωêx^{(i+1)} = x^{(i)} + \alpha\hat{p} + \omega\hat{e}, 残差を漸化式r(i+1)=e−ωvr^{(i+1)} = e - \omega vで更新する (方法の全体は利用者ガイドのアルゴリズム. ω\omegaは利用者ガイドのc3c_{3}, ρ\rhoはc1c_{1}). 収束判定には pcg と同じく更新直後の漸化式の相対残差∥r(i+1)∥/∥b∥\|r^{(i+1)}\| / \|b\|を用いる. 反復の前に初期残差の相対残差がtoltol未満なら, pcg と同じく反復せずに CONVERGED_RTOL (反復回数 0, 解は初期値のまま, 残差・真の残差は初期残差の相対残差) を返す. 破綻はα\alpha, ω\omega, 次の探索方向の係数β=ρ(i+1)/(⟨r*,q⟩ω)\beta = \rho^{(i+1)} / (\langle r^{\ast},q \rangle\omega)をそれぞれ作る前に調べる. 結果は次のとおりである (反復の中で上の行から順に調べる).

調べる時点 条件 収束状態 解 反復回数 残差
α\alphaを作る前 ⟨r*,q⟩\langle r^{\ast},q \rangleが 0 または非有限 DIVERGED_BREAKDOWN その反復の開始時のx(i)x^{(i)} ii 前の反復の相対残差 (1 反復目では初期残差の相対残差)
ω\omegaを作る前 v=0v = 0 (⟨v,v⟩=0\langle v,v \rangle = 0) で∥e∥/∥b∥\|e\|/\|b\|が非有限 DIVERGED_NANORINF x(i)+αp̂x^{(i)} + \alpha\hat{p} i+1i + 1 ∥e∥/∥b∥\|e\|/\|b\|
同上 v=0v = 0 で∥e∥/∥b∥<tol\|e\|/\|b\| < tol CONVERGED_RTOL x(i)+αp̂x^{(i)} + \alpha\hat{p} i+1i + 1 ∥e∥/∥b∥\|e\|/\|b\|
同上 v=0v = 0 でそれ以外 DIVERGED_BREAKDOWN x(i)+αp̂x^{(i)} + \alpha\hat{p} i+1i + 1 ∥e∥/∥b∥\|e\|/\|b\|
更新の後 相対残差が非有限 DIVERGED_NANORINF x(i+1)x^{(i+1)} i+1i + 1 その非有限値
同上 相対残差 <tol< tol CONVERGED_RTOL x(i+1)x^{(i+1)} i+1i + 1 その相対残差
収束判定の後 ω=0\omega = 0 またはρ(i+1)=0\rho^{(i+1)} = 0 (β\betaを作れない) DIVERGED_BREAKDOWN x(i+1)x^{(i+1)} i+1i + 1 その相対残差
NN回の反復の後 上に当たらない DIVERGED_ITS x(N)x^{(N)} NN 最後の相対残差

　v=Aê=0v = A\hat{e} = 0はeeが 0 となる「幸運な破綻」である. このときω\omegaは0/00/0になるので作らず, x(i)+αp̂x^{(i)} + \alpha\hat{p}で打ち切る. ω=0\omega = 0またはρ(i+1)=0\rho^{(i+1)} = 0の検出は収束判定の後に行うので, 収束した反復では破綻としない. いずれの判定も全ランクで集約した内積から行うので, 全ランクが同じ分岐を取る. ∥b∥=0\|b\| = 0の場合は線形ソルバに共通の扱いによる.

　rank 0 は反復ごとに反復回数 : residual norm = ...の行を書く (v=0v = 0で打ち切った反復では∥e∥/∥b∥\|e\|/\|b\|). v=0v = 0以外の破綻ではpbicgstab breakdown :に続けて原因 (<r0,q> = 0, <r0,q> is not finite, omega (c3) = 0, rho (<r0,r>) = 0) と反復回数を書く. pcg と同じく, 真の相対残差∥b−Ax∥/∥b∥\|b - Ax\| / \|b\|は終了時に計算してfinish : residual true normの行に書き, 真の残差として返すだけである.

　内積の計算精度を FP16 にした構成では, 相対残差が精度の下限に近づくと⟨r*,q⟩\langle r^{\ast},q \rangleが 0 または非有限となり, DIVERGED_BREAKDOWN で終わることがある (利用者ガイドの「低精度での既知の限界」).

2.3 pgmres

　収束判定は各リスタートjj (j=0,1,…,J−1j = 0, 1, \ldots, J - 1. J=⌈N/m⌉J = \lceil N/m \rceil) の先頭で, その時点の近似解x(j)x^{(j)} (x(0)x^{(0)}は初期値) から計算した真の残差r=b−Ax(j)r = b - Ax^{(j)}の相対残差∥r∥/∥b∥\|r\| / \|b\|により行う. 満たさなければv1=r/∥r∥v_{1} = r / \|r\|からAK−1AK^{-1}の Arnoldi 過程をmm列進め, 残差ノルムを最小にする修正でx(j+1)x^{(j+1)}を求めて次のリスタートに進む (方法の全体は利用者ガイドのアルゴリズム). Arnoldi 過程の途中では判定しない. Givens 回転で得る残差ノルム (回転後の右辺の最終成分) は判定に用いず, 幸運な破綻 (次段落) が起きない限りmm列を作ってから解を更新する. 結果は次のとおりである.

条件 収束状態 解 反復回数 残差
リスタートjjの先頭で相対残差が非有限 DIVERGED_NANORINF x(j)x^{(j)} jmjm その非有限値
リスタートjjの先頭で相対残差 <tol< tol CONVERGED_RTOL x(j)x^{(j)} jmjm その相対残差
リスタートjjの Arnoldi 過程でhk,ih_{k,i}またはhi+1,ih_{i+1,i}が非有限 DIVERGED_NANORINF x(j)x^{(j)} (更新しない) jmjm リスタートjjの先頭の相対残差
リスタートjjの幸運な破綻で, 更新に使える列が無い (1 列目でHHが特異) DIVERGED_BREAKDOWN (注) x(j)x^{(j)} (更新しない) jmjm 終了時の真の相対残差
JJ回のリスタートを終えた 終了時の真の相対残差がtoltol未満なら CONVERGED_RTOL, 非有限なら DIVERGED_NANORINF, それ以外は DIVERGED_ITS x(J)x^{(J)} NN 終了時の真の相対残差

　(注) 終了時の真の相対残差がtoltol未満なら CONVERGED_RTOL とする (xxを更新していないので, 通常は起きない).

　反復回数はリスタート回数とmmの積として数える (幸運な破綻で列を打ち切ったリスタートもmmと数える). NNがmmの倍数でない場合は, 最後のリスタートだけN−(J−1)mN - (J-1)m列で Arnoldi 過程を止め, その列数で最小二乗問題を解いて解を更新する. したがって反復上限に達した場合の反復回数はNNちょうどである (N<mN < mでもNN回反復する). NNがmmの倍数なら, すべてのリスタートがmm列である. 真の相対残差は終了時にも計算してfinish : residual true normの行に書き, 真の残差として返す. rank 0 は各リスタートの先頭で反復回数 : residual norm = ...の行を書く. ∥b∥=0\|b\| = 0の場合は線形ソルバに共通の扱いによる.

　Arnoldi 過程のii列目では, w=AK−1viw = AK^{-1}v_{i}をv1,…,viv_{1},\ldots,v_{i}に対して直交化し, その係数をhk,ih_{k,i} (k=1,…,ik = 1,\ldots,i), 直交化後のノルム∥w∥\|w\|をhi+1,ih_{i+1,i}とする. hi+1,ih_{i+1,i}が, 直交化前のwwのノルム∑k≤ihk,i2+hi+1,i2\sqrt{\sum_{k \leq i} h_{k,i}^{2} + h_{i+1,i}^{2}}の10−1410^{-14}倍以下 (または 0) になった場合は, Krylov 部分空間が不変になった「幸運な破綻」とみなす. hi+1,i=0h_{i+1,i} = 0としてii列目にも Givens 回転を施し, その列で Arnoldi 過程を打ち切る. 回転後の対角要素hi,ih_{i,i}が 0 でなく有限ならば先頭ii列, そうでなければ先頭i−1i - 1列で最小二乗問題を解いてx(j+1)x^{(j+1)}を求め, 次のリスタートの先頭で真の残差により判定する. rank 0 はpgmres : Arnoldi breakdown at column ...の行を書く. 使える列が無い (i=1i = 1でh1,1h_{1,1}が 0) 場合は上表のとおり DIVERGED_BREAKDOWN で終える.

　直交化の方式を古典 Gram-Schmidt とした場合は, 既定の修正 Gram-Schmidt 法 (hk,i=⟨w,vk⟩h_{k,i} = \langle w,v_{k} \rangleの計算とw=w−hk,ivkw = w - h_{k,i}v_{k}の更新をk=1,…,ik = 1,\ldots,iの順に行う) の代わりに, hk,i=⟨w,vk⟩h_{k,i} = \langle w,v_{k} \rangle (k=1,…,ik = 1,\ldots,i) をまとめて計算し (集団通信 1 回), w=w−∑khk,ivkw = w - \sum_{k} h_{k,i}v_{k}とする.

2.4 pcagmres

　本節はQQを作る場合 (QQの作り方が AUTO・EXPLICIT) の扱いである. IMPLICIT の扱いは次節に示す. 方法の全体は利用者ガイドのアルゴリズムに示す.

　収束判定は pgmres (pgmres) と同じく, 各リスタートjj (j=0,1,…,J−1j = 0, 1, \ldots, J - 1. J=⌈N/(st)⌉J = \lceil N/(st) \rceil) の先頭で, 真の残差r=b−Ax(j)r = b - Ax^{(j)}の相対残差∥r∥/∥b∥\|r\| / \|b\|により行う. 基底の生成と Givens 回転の途中では判定せず, 幸運な破綻 (下記) が起きない限り 1 回のリスタートでss本ずつttブロック, 計stst本の基底を作ってから解を更新する. Givens 回転は, tt個のブロックぶんの Hessenberg 行列を組み立ててからまとめて行う. 反復の前にも初期残差で判定する (線形ソルバに共通の扱い). 結果は次のとおりである.

条件 収束状態 解 反復回数 残差
反復の前に初期残差の相対残差 <tol< tol CONVERGED_RTOL 初期値 (変えない) 0 初期残差の相対残差 (真の残差も同じ値)
リスタートjjの先頭で相対残差が非有限 DIVERGED_NANORINF x(j)x^{(j)} jstjst その非有限値

2.5 pcagmres (QQを作らない場合)

    1. 有効次元jjがnevnev以上なら, HHの先頭j×jj \times jブロックの Ritz 対のうち|θ||\theta|の大きいnevnev個について, 真の残差∥Opx−θx∥/(|θ|∥x∥)\|\mathrm{Op}\,x - \theta x\| / (|\theta|\|x\|)を計算する (x=Vjyx = V_{j}y. Op\mathrm{Op}の適用をnevnev回程度追加で行う). すべてがtoltol以下なら, 有効次元jjで Arnoldi 分解の拡張とリスタートを打ち切って終了し, CONVERGED_RTOL とする. 残差はこの真の残差の最大値である.
    1. 確かめられない場合 (有効次元がnevnev未満, または真の残差がtoltolを超える) は止めずに, 大域行番号とリスタート番号・列番号から作る乱数ベクトルをVjV_{j}に対して CGS2 で直交化してvj+1v_{j+1}とし, hj+1,j=0h_{j+1,j} = 0のままmmまで Arnoldi 分解を続ける (HHはブロック上三角になる). 乱数ベクトルは行番号だけから決まるので, MPI の分割数によらない. 1 回の Arnoldi 過程で入れる乱数方向は 3 本までとする.
  • 乱数方向を入れた基底では残差推定が 0 のブロックが残るので, 残差推定がtoltolを満たしても, (A) と同じ真の残差で確かめてから収束とする. 満たさなければ DIVERGED_BREAKDOWN とする.
  • 乱数方向が 3 本を超えた場合, または乱数ベクトルが直交化でほぼ消えた (直交化後のノルムが直交化前の10−1010^{-10}倍以下. VjV_{j}が張る空間で尽きた) 場合は, その有効次元で打ち切り, 真の残差で確かめられないので DIVERGED_BREAKDOWN とする. 有効次元がnevnev未満の場合も DIVERGED_BREAKDOWN である.

　有効次元がkkeepk_{keep}より小さいまま終えた場合は, 足りない固有値・固有ベクトルを 0 として返す (rank 0 がその旨を表示する).

　HHの固有分解は LAPACK のdgeev, リスタートのための実 Schur 分解と並べ替えはdgees・dtrsenでホスト側で計算する. これらは rank 0 だけが計算して結果を全ランクに配る (HHも rank 0 の値に揃える) ので, 丸めの差で分岐がランクごとに割れることはない. LAPACK が失敗した (info が 0 でない. dtrsenの後に保持する本数が 1 以上mm未満でない場合を含む) 場合は DIVERGED_BREAKDOWN とする. |θ||\theta|による並べ替えでは NaN を最後に回す. 途中の判定と打ち切りの理由は, rank 0 が[KS]で始まる行に書く.

　出力は|θ||\theta|の降順にkkeepk_{keep}個である (収束判定の対象は先頭nevnev個. 固有値と固有ベクトルの出力). shift-invert では|θ||\theta|の大きい順がσ\sigmaに近い順に当たる. shift-invert の逆変換で|θ|2≤10−300|\theta|^{2} \leq 10^{-300}となる Ritz 値は, 固有値として+∞+\inftyを返す.

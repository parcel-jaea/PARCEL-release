4 PARCELデータ型

概要　テンプレート引数で精度を指定するための型 (以下 parceltype と記す) と整数型である. いずれもグローバル名前空間にある (名前空間 parcel の外). 行列・ベクトルのデータ精度 (parcel::matrix<T>, parcel::vector<T>) とソルバの演算精度 (クラステンプレート引数) の両方にこの型を与える. 精度のテンプレート引数は省略でき, 省略した場合は parcel_double である (parcel::matrix<>, parcel::vector<>, parcel::krylov::pcg<> など. solver() のテンプレート引数).

書式

using parcel_double       = parcel::floatingtype<double>;
using parcel_float        = parcel::floatingtype<float>;
using parcel_longdouble   = parcel::floatingtype<long double>;
using parcel_fp16         = parcel::floatingtype<sycl::half>;
using parcel_doubledouble = parcel::doubledouble;
#define PARCEL_INT  int64_t         // -DPARCEL_INT32 で int32_t
#define PARCEL_LINT int32_t         // -DPARCEL_LOCAL_INT64 で int64_t
型名 内容
parcel_fp16 sycl::half 型 (半精度)
parcel_float float 型 (単精度)
parcel_double double 型 (倍精度)
parcel_longdouble long double 型
parcel_doubledouble double-double 型 (4倍精度相当). 上位・下位の 2 本の double 配列で保持する
PARCEL_INT 行番号・列番号・行数・非零数・反復回数などの整数型. 既定は int64_t (MPI では MPI_INT64_T). -DPARCEL_INT32 を付けてビルドすると int32_t (MPI_INT32_T) になる (-DPARCEL_INT32=0 は 64 ビット). -DPARCEL_INT は 64 ビットの指定として受け付ける (値は見ない). -DPARCEL_INT と -DPARCEL_INT32 を両方指定すると #error. 選ばれた幅はマクロ PARCEL_INT_BITS (64 / 32) で分かる
PARCEL_LINT 1 つのランクの中の添字の型. デバイス上の CRS の行ポインタと局所化した列番号, 袖通信で送る要素の番号, SpMV・前処理のカーネルで使う. 既定は int32_t (MPI_INT32_T). -DPARCEL_LOCAL_INT64 (値が 0 以外) を付けてビルドすると int64_t (MPI_INT64_T) になる. -DPARCEL_INT32 では int32_t. -DPARCEL_INT32 と -DPARCEL_LOCAL_INT64 を両方指定すると #error. 選ばれた幅はマクロ PARCEL_LINT_BITS (32 / 64) で分かる. API の引数には現れない

注意　parcel_fp16 を使う構成では, 精度で届く相対残差に下限があり, それより小さい収束判定値では停滞するか NaN で破綻する. FP16 では pcagmres の Cholesky QR 系 (CAGMRES_Q_IMPLICIT とモーメント法) を使えない. 制約の詳細は使用方法の章の「精度の指定」に示す.

　set_crsMat() に渡す CRS の行ポインタと列番号の配列は PARCEL_INT (既定 8 バイト) である. デバイス上の CRS は PARCEL_LINT で持つので, 既定では列番号と行ポインタが 4 バイト, 倍精度の行列では 1 非零要素あたり値と合わせて 12 バイトである. -DPARCEL_LOCAL_INT64 では 8 バイト (倍精度で 1 非零要素 16 バイト) になり, SpMV (疎行列ベクトル積) のメモリ転送量が増える. -DPARCEL_INT32 では両方とも 4 バイトになる (行数が 231−12^{31} - 1 以下の問題に限る). C言語・Fortran の API の行数・非零数・行ポインタ・列番号は PARCEL_INT によらず 64 ビット (C の parcel_int, Fortran の integer(parcel_int_kind)) である (使用方法の章).

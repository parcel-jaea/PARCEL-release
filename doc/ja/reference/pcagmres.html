14 parcel::krylov::pcagmres

　通信削減型一般化最小残差法 (CA-GMRES) のクラスである. 正規直交基底 QQ を陽に作るかどうかを set_explicit_q() で選ぶ. QQ を作らない場合 (CAGMRES_Q_IMPLICIT) の扱いは本章の後半の「Q を作らない場合」に示す.

14.1 pcagmres (クラス)

概要　前処理付き通信削減型一般化最小残差法. ss 本の基底をまとめて作り, QR 分解で直交化する.

書式

template< class Tspmv = parcel_double, class Tprecon = parcel_double,
          class Taxpy = parcel_double, class Tdot    = parcel_double >
class pcagmres : public krylov_param;

注意　FP16 のデータ精度・計算精度では, Cholesky QR 系 (CAGMRES_Q_IMPLICIT と QR_CAGMRES_CHOLESKYQR) を使わない (ss, tt によらず NaN または未収束になる. 検査はしない). QQ を作る方式は既定の (s,t)(s, t) で使える (利用者ガイドの「低精度での既知の限界」). -DPARCEL_ENABLE_PCAGMRES=0 でビルドから外せる (QQ の作り方によらずクラス全体が外れる).

関連項目　収束判定と破綻の扱い, set_restart(), set_qr_algo(), set_explicit_q(), 線形ソルバの章

14.2 solver()

概要　Ax=bAx = b を解く.

書式

template< class Tmat, class Tvecx, class Tvecb, class Tvec = parcel_double,
          class Tprecon_mat = parcel_double, class Tprecon_vec = parcel_double,
          class Tbasis = parcel_double, class TcalcQR = parcel_double,
          class THessenberg = parcel_double,
          class Todd_basis = Tbasis, class Teven_basis = Tbasis >
void solver(parcel::matrix<Tmat> &Mat, parcel::vector<Tvecx> &x0, parcel::vector<Tvecb> &b0);

引数

名前 入出力 型 説明 既定値
Tbasis 入力 (テンプレート) PARCELデータ型 基底ベクトルのデータ精度. CAGMRES_Q_IMPLICIT では前処理の入出力 (基底から作る作業ベクトル) のデータ精度であり, Todd_basis・Teven_basis の既定値 parcel_double
TcalcQR 入力 (テンプレート) PARCELデータ型 QR分解の計算精度 (CAGMRES_Q_IMPLICIT では Gram 行列の計算精度) parcel_double
THessenberg 入力 (テンプレート) PARCELデータ型 Hessenberg 行列の精度 (CAGMRES_Q_IMPLICIT では Gram 行列の格納にも使う) parcel_double
Todd_basis 入力 (テンプレート) PARCELデータ型 奇数番目の基底ベクトルの格納精度. CAGMRES_Q_IMPLICIT のときだけ使う Tbasis
Teven_basis 入力 (テンプレート) PARCELデータ型 偶数番目の基底ベクトルの格納精度. CAGMRES_Q_IMPLICIT のときだけ使う Tbasis
Mat, x0, b0 pcg の solver() と同じ なし

　Tmat から Tprecon_vec までは「solver() のテンプレート引数」と同じである.

前提条件　共通の前提条件 (in-order キュー, 登録済みの行列, ベクトルのキューと長さ) を満たすこと. QQ の作り方と QR 分解の組合せが set_explicit_q() の規則を満たすこと (入口で検査し, 違反は全ランクが std::invalid_argument). get_max_iteration() ≥s×t\geq s \times t であること (検査しない). b=0b = 0 では pcg と同じく x=0x = 0 で戻る.

戻り値　なし.

MPI　集団操作. 全ランクが同じ設定で呼ぶ.

例

parcel::krylov::pcagmres<> ca;
ca.solver(A, x, b);   // 推論できない精度はすべて parcel_double

14.3 set_restart() / get_restart_s() / get_restart_t()

概要　1 回の基底生成で作るベクトル数 ss と, リスタートまでの基底生成回数 tt を設定・取得する. リスタート周期は s×ts \times t である.

書式

void       set_restart(PARCEL_INT cagmres_s, PARCEL_INT cagmres_t);
PARCEL_INT get_restart_s() const;
PARCEL_INT get_restart_t() const;

引数

名前 入出力 型 説明 既定値
cagmres_s 入力 PARCEL_INT ss 8
cagmres_t 入力 PARCEL_INT tt 4

前提条件　いずれも 1 以上. 0 以下は std::invalid_argument.

MPI　局所操作. 全ランクで同じ値を与える.

注意　CAGMRES_Q_IMPLICIT では Cholesky QR 法の直交性の誤差が基底の条件数の 2 乗に比例するので, ss を大きくすると収束が悪化しうる.

例

ca.set_restart(8, 1);

14.4 set_qr_algo() / get_qr_algo()

概要　基底の QR 分解法を設定・取得する.

書式

void       set_qr_algo(PARCEL_INT qrdecomposition_algo);
PARCEL_INT get_qr_algo() const;

引数

名前 入出力 型 説明 既定値
qrdecomposition_algo 入力 PARCEL_INT parcel::qr::QR_CGS (0), QR_MGS (1), QR_CHOLESKYQR (2), QR_CAGMRES_CHOLESKYQR (202, モーメント法. CAGMRES_Q_IMPLICIT 専用) QR_MGS (CAGMRES_Q_IMPLICIT で呼ばない場合は QR_CHOLESKYQR)

前提条件　上の 4 値のいずれか. それ以外の値は std::invalid_argument. set_explicit_q() との組合せは solver() の入口で検査する.

戻り値　get_qr_algo() は solver() が実際に使う値 (CAGMRES_Q_IMPLICIT でこの関数を呼んでいなければ QR_CHOLESKYQR).

MPI　局所操作. 全ランクで同じ値を与える.

関連項目　QR分解の章, Q を作らない場合

例

ca.set_qr_algo(parcel::qr::QR_MGS);

14.5 set_explicit_q() / get_explicit_q()

概要　正規直交基底 QQ を陽に作るかどうかを設定・取得する.

書式

const PARCEL_INT parcel::krylov::CAGMRES_Q_AUTO     = 0;
const PARCEL_INT parcel::krylov::CAGMRES_Q_EXPLICIT = 1;
const PARCEL_INT parcel::krylov::CAGMRES_Q_IMPLICIT = 2;

void       set_explicit_q(PARCEL_INT mode);
PARCEL_INT get_explicit_q() const;

引数

名前 入出力 型 説明 既定値
mode 入力 PARCEL_INT 下表の定数のいずれか CAGMRES_Q_AUTO
定数 (parcel::krylov::) 値 動作
CAGMRES_Q_AUTO 0 QR_CHOLESKYQR かつ t=1t = 1 のときだけ QQ を作らず, それ以外は QQ を作る
CAGMRES_Q_EXPLICIT 1 常に QQ を作る (QR_CHOLESKYQR で t=1t = 1 でも作る)
CAGMRES_Q_IMPLICIT 2 どの tt でも QQ を作らない. QR 分解は Cholesky QR 法 (QR_CHOLESKYQR または QR_CAGMRES_CHOLESKYQR) に限る (Q を作らない場合)

前提条件　上の 3 値のいずれか. それ以外の値は std::invalid_argument. set_qr_algo() との組合せは, 設定関数を呼ぶ順序によらないよう solver() の入口で検査し, 次の場合に std::invalid_argument を投げる (全ランクで同じ判定).

  • CAGMRES_Q_IMPLICIT で QR_CGS または QR_MGS を明示した (set_qr_algo() を呼んでいなければ QR_CHOLESKYQR を使う).
  • QR_CAGMRES_CHOLESKYQR を CAGMRES_Q_AUTO または CAGMRES_Q_EXPLICIT と組み合わせた.
  • QR_CAGMRES_CHOLESKYQR で, 前処理なし (PRECON_NONE) でない, または ss が 2 以上の偶数でない.

　QR_CAGMRES_CHOLESKYQR は AA が対称の場合に限る. これは検査せず, 非対称な AA では誤った RR を用いて誤った結果を返す.

戻り値　get_explicit_q() は設定値.

MPI　局所操作. 全ランクで同じ値を与える.

注意　CAGMRES_Q_AUTO と CAGMRES_Q_EXPLICIT は, t=1t = 1 の QR_CHOLESKYQR 以外では同じ計算を行う. CAGMRES_Q_IMPLICIT は計算の順序が異なるので, 同じ ss, tt と QR 分解でも結果は丸め誤差の範囲で異なる.

関連項目　Q を作らない場合, QR分解の章

例

ca.set_explicit_q(parcel::krylov::CAGMRES_Q_IMPLICIT);   // QR 分解は指定しなければ QR_CHOLESKYQR

14.6 CAGMRES_Q_IMPLICIT (Q を作らない場合)

概要　set_explicit_q(CAGMRES_Q_IMPLICIT) を指定すると, 同じ CA-GMRES(s,t) を正規直交基底 QQ を陽に作らずに解く. 基底 VV の Gram 行列の Cholesky 分解から RR だけを求め, 解の更新に V(R−1y)V(R^{-1}y) を用いる. 基底は奇数番目と偶数番目で格納精度を変えられる (solver() の型引数 Todd_basis・Teven_basis).

前提条件　QR 分解は Cholesky QR 法 (QR_CHOLESKYQR または QR_CAGMRES_CHOLESKYQR (モーメント法)) に限る. 組合せの規則は set_explicit_q() に示す.

注意　収束判定, 収束状態, 幸運な破綻の扱いは QQ を作る場合と同じである. 終了時の真の相対残差を計算し, get_true_residual() で返す.

関連項目　収束判定と破綻の扱い, 線形ソルバの章の Q を作らない CA-GMRES の節, QR分解の章のモーメント法, set_explicit_q()

例

parcel::krylov::pcagmres<> cq;
cq.set_explicit_q(parcel::krylov::CAGMRES_Q_IMPLICIT);
cq.set_restart(8, 1);
cq.set_qr_algo(parcel::qr::QR_CAGMRES_CHOLESKYQR);   // A が対称で前処理なしの場合のみ.省けば QR_CHOLESKYQR
cq.solver(A, x, b);

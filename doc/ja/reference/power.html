15 parcel::krylov::power

15.1 power (クラス)

概要　べき乗法. AA (set_precon_spectrum(true) 時は AK−1AK^{-1}) の絶対値最大の固有対を求める.

書式

template< class Tspmv = parcel_double, class Tprecon = parcel_double,
          class Taxpy = parcel_double, class Tdot    = parcel_double >
class power : public eigen_param;

注意　固有のメンバ関数は無い. 固有値ソルバ共通のメンバ関数のうち set_precon_spectrum() だけを使う. set_tolerance() は固有値の相対変化に, set_max_iteration() は反復回数に対する値である. 収束判定と破綻の扱いはソルバごとの収束判定に示す.

15.2 solver()

概要　絶対値最大の固有値と固有ベクトルを求める.

書式

template< class Tmat, class Teigen_val, class Teigen_vec, class Tvec = parcel_double,
          class Tprecon_mat = parcel_double, class Tprecon_vec = parcel_double >
void solver(parcel::matrix<Tmat> &Mat,
            parcel::vector<Teigen_val> &EigenValue, parcel::vector<Teigen_vec> &EigenVec);

引数

名前 入出力 型 説明 既定値
Mat 入力 parcel::matrix<Tmat> & 係数行列 なし
EigenValue 出力 parcel::vector<Teigen_val> & 固有値. 要素数 1 以上 (全要素に同じ値が入る) なし
EigenVec 出力 parcel::vector<Teigen_vec> & 固有ベクトル (担当行ぶん). 要素数は担当行数 なし

前提条件　共通の前提条件 (in-order キュー, 登録済みの行列, ベクトルのキューと長さ) を満たすこと. 絶対値最大の固有値が実数で, 絶対値が 2 番目の固有値と分離していること (検査しない. 複素共役対では収束しない).

戻り値　なし.

MPI　集団操作. 全ランクが同じ設定で呼ぶ.

注意　初期ベクトルは内部で大域行番号から作るので, EigenVec の入力値は使われない. 各ランクの先頭行は MPI_Exscan で求めるので, 初期ベクトルは行分割によらない.

例

parcel::krylov::power<> pw;
pw.solver(A, lam, v);   // lam, v は parcel::vector<>
